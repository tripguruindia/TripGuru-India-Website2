# TripGuru Website

TripGuru is the public travel website for international packages, flights, hotels, visas, and lead capture through InTravWeb.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- React Router
- InTravWeb API integration

## Quick Start

```bash
cp .env.example .env.local
npm install
npm run dev
```

For production builds:

```bash
npm run lint
npm run build
```

## Scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Start the Vite development server |
| `npm run lint` | Run TypeScript checks |
| `npm run build` | Build the site and regenerate sitemap output |
| `npm run preview` | Preview the production build locally |

## InTravWeb Integration

Set `VITE_INTRAVWEB_API_BASE` to the deployed InTravWeb backend URL.

```env
VITE_INTRAVWEB_API_BASE=https://intravweb.onrender.com
```

The site reads:

- `GET /api/offers/public/tripguru`
- `POST /api/leads/tripguru`

## SEO

- Route metadata is managed in `src/components/seo/SeoManager.tsx`
- City landing pages are configured in `src/cityLandingPages.ts`
- Sitemap is generated by `scripts/postbuild-sitemap.mjs`
- Production domain: `https://www.tripguruindia.com`
